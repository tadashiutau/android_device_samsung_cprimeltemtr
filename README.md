# android_device_samsung_cprimeltemtr

## Device tree for Samsung Galaxy Core Prime [SM-G360T1, MetroPCS]

Based on Galaxy-MSM8916's coreprimeltespr (SM-G360P) tree. Same "rossa" board;
this variant uses the TMO board DT (msm8916-sec-rossatmo-r00), the SM5504 MUIC,
the SR544/SR200PC20 cameras, GSM/LTE radio and no NFC.

Basic   | Spec Sheet
-------:|:-------------------------
CPU     | Qualcomm MSM8916 Quad-core 1.2 GHz ARM Cortex-A53
GPU     | Adreno 306
Memory  | 1 GB
Shipped Android Version | 5.1.1
Storage | 8 GB
Display | 480 x 800, 4.5"
Rear Camera  | 5.0 MP (SR544), LED flash
Front Camera | 2.0 MP (SR200PC20)
